# BetterEvent

BetterEvent 是一个《杀戮尖塔 2》（Slay the Spire 2）事件优化 Mod。它为部分事件增加新的选择、改善随机奖励的可控性，并为一些强制交互事件补充安全离开的选项。

当前版本：`v1.0.2`  
作者：`YY`

## 功能介绍

### 事件内容调整

| 事件 | 调整内容 |
| --- | --- |
| 害虫杀手 | 增加新的卡牌变化结果，并可选择拒绝交易获得金币。 |
| 色彩哲学家 | 将可选内容扩展至所有角色。 |
| 蘑菇饥渴 | 可选择强忍饥饿并升级一张牌，或吃下全部蘑菇获得对应遗物。 |
| 被寄生的自动机械 | “学习”改为三张能力牌三选一；“触碰核心”改为三张基础耗能为 0 的非 X 费牌三选一。 |
| 重拳出击 | 增加“偷袭”选项，可获得随机药水、金币和卡牌奖励。 |
| 反射 | 可谨慎试探并复制一张非任务牌，也可以直接离去。 |
| 遗物交换商 | 增加新的交易入口，并可反复刷新当前交易货物。 |
| 滑脚木桥 | 增加多种风险与收益不同的过桥选择，也可折返回复生命。 |
| 茶艺大师 | 增加额外选择，可获得多种茶类遗物或金币。 |
| 传说是真的 | 可带走地图并出售，获得金币。 |
| 打造时间 | 不再只随机展示两种卡牌类型和附加效果，而是展示全部三种选择。 |
| 垃圾堆 | 将部分随机奖励改为玩家主动选择，并增加离去选项。 |
| 审判 | 初始阶段增加逃走选项。 |
| 旺购百货 | 增加购买随机药水和交换卡牌等额外选择。 |
| 修禅织网者 | 可扯碎蛛网并获得金币。 |

## 本地化与兼容性

- 支持简体中文和英文。
- Mod 包含托管的 .NET 程序集，不捆绑平台专用原生库。
- 项目以 AnyCPU/MSIL 方式构建，并为 PCK 使用 `msil` 特性，面向 Windows、Linux 及 macOS ARM64 环境。
- 本 Mod 会影响游戏内容；多人游戏时，建议所有玩家使用相同版本和相同的 Mod 加载顺序。
- 游戏更新可能导致事件内部结构变化。如更新后出现异常，请先确认 Mod 是否已有适配版本。

## 安装方法

### Steam 创意工坊

订阅创意工坊中的 BetterEvent，并在游戏的 Mod 管理界面中启用。

### 手动安装

1. 下载发布包并解压。
2. 在游戏的 `mods` 目录下创建 `BetterEvent` 文件夹。
3. 将以下文件放入该文件夹：
   - `BetterEvent.dll`
   - `BetterEvent.pck`
   - `BetterEvent.json`
4. 启动游戏，在 Mod 管理界面中启用 BetterEvent。

最终目录结构应类似：

```text
mods/
└── BetterEvent/
    ├── BetterEvent.dll
    ├── BetterEvent.json
    └── BetterEvent.pck
```

## 从源码构建

构建环境需要：

- .NET 9 SDK
- Godot/MegaDot 4.5.1（.NET 版本）
- 已安装《杀戮尖塔 2》，以便引用游戏程序集

在项目根目录执行：

```powershell
dotnet restore BetterEvent.csproj
dotnet build BetterEvent.csproj -c Release --no-restore -t:BuildMod
```

构建产物会输出到 `build` 目录。若本机 Godot/MegaDot 路径与项目配置不同，请修改项目中的 `GodotExecutable`，或在构建时传入对应属性。
